How it works

Five steps. No mystery in between.

You'll always know what's happening and when — most projects follow this exact path.

  1. 01

    Discover 1–2 days

    A short call and questionnaire to nail down your goals, audience, and must-haves.

  2. 02

    Design 3–5 days

    Visual direction and key page layouts, shared for feedback before a single line of code is built out.

  3. 03

    Build 1–8 weeks, by scope

    The site gets built — responsive, fast, and tested across devices as we go.

  4. 04

    Launch 1–2 days

    Final QA, content check, and a clean cutover to production — with zero-downtime deploys.

  5. 05

    Support ongoing

    A Care Plan (or ad hoc requests) keeps things running long after launch day.

FAQ

Questions we hear a lot

How long does a project take?

Most Launch sites take 2–3 weeks, Growth sites 4–6 weeks, and Commerce/custom builds 6–10 weeks, depending on scope and how quickly we get feedback and content from you.

Do I own my website after it's built?

Yes. The full source code lives in a GitHub repository under your account (or transferred to you at launch), so you're never locked into us or a proprietary platform.

What if I need changes after launch?

A Care Plan covers ongoing updates and monitoring. For one-off changes, we're happy to quote hourly or per-request instead.

Do you write the content and copy too?

We can work from copy you provide, help you refine it, or draft it for you as an add-on — let us know what you need during the Discover step.

What do you actually build sites with?

Modern, hand-built code rather than bloated page-builder plugins, deployed on a global edge network for speed, security, and uptime — not a slow shared server.

Can you redesign my existing site instead of building new?

Yes — redesigns and migrations fit into any tier above; we'll scope it the same way during Discover.
